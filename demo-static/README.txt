Naija Area: static demo

Double-click index.html (Chrome, Edge, Firefox or Safari with WebGL). No server, no internet needed.
The real game rules run in the page on a JS build of SQLite (sql.js). A few friendly bots walk around and a practice bot (@Practice_Bot) will join any FRIENDLY Whot/Ludo table you sit at.
Shops and venues are always open in the demo. Limits: reload = new world; no second human player, no advertiser/admin pages, no live push. Use the real server (npm start) for those.
Rebuild: npm run build:demo
