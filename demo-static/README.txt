Naija Area: static demo

Double-click index.html (Chrome, Edge, Firefox or Safari with WebGL). No server needed. Internet is needed ONLY for the in-car radio.
In-car radio: the four real Lagos stations (Cool FM, Wazobia FM, Nigeria Info, The Beat) are ON. They stream live from each station's own servers; NOT verified by ear and no station has given written permission yet (a flagged risk; Sherif approved proceeding). Some browsers block live streams on file://: then the car plays the invented stations instead, and the chip says Tap to play if the browser needs a tap. Press R in a car to switch the radio off.
The real game rules run in the page on a JS build of SQLite (sql.js). A few friendly bots walk around and a practice bot (@Practice_Bot) will join any FRIENDLY Whot/Ludo table you sit at.
Shops and venues are always open in the demo. Limits: reload = new world; no second human player, no advertiser/admin pages, no live push. Use the real server (npm start) for those.
Rebuild: npm run build:demo
